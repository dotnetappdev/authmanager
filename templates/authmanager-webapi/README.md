# AuthManagerWebApi1

A standalone ASP.NET Core Web API with ASP.NET Identity and [DotNetAuthManager](https://github.com/dotnetappdev/authmanager)
pre-wired — a Keycloak-style admin UI and REST API, generated by `dotnet new authmanager-webapi`.

## Run it

```bash
dotnet run
```

- Swagger: `https://localhost:5001/swagger`
- Admin UI: `https://localhost:5001/authmanager` — sign in with `superadmin@example.com` / `SuperAdmin@123456!`
  (change `SeedSuperAdminPassword` in `Program.cs` before deploying anywhere real)
- Admin REST API: `https://localhost:5001/authmanager/api/*`

## What you get

- `POST /register`, `POST /login` — your own app's account endpoints (cookie auth)
- `/authmanager` — the full Keycloak-style admin panel: users, roles, groups, claims, sessions,
  API tokens, OAuth2 clients, license keys, customer API keys, subscriptions, audit log, and more
- `/authmanager/api/*` — the same capabilities as JSON, for building your own frontend instead

## Database: SQLite or SQL Server

SQLite by default — no install needed. Switch to SQL Server by editing `appsettings.json`:

```json
{
  "Database": { "Provider": "SqlServer" },
  "ConnectionStrings": { "Default": "Server=.;Database=AuthManagerWebApi1;Trusted_Connection=True;TrustServerCertificate=True" }
}
```

Both your own Identity store and AuthManager's internal store (audit log, sessions, tokens,
licenses) follow this one setting.
